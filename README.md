# Bug Tracker

A simple bug tracker built with Flask (Python) and JavaScript.

## Features
- Add bugs with a title and priority (Low, Medium, High)
- Close and reopen bugs
- Delete bugs with a confirmation popup
- Search bugs as you type
- Priority colors (red, orange, green)
- Closed bugs are crossed out
- Bugs are saved in a JSON file

## How to run
1. Install Flask: pip install flask
2. Run the app: python app.py
3. Open http://127.0.0.1:5000 in your browser

## Built with
- Python (Flask)
- HTML, CSS, JavaScript
